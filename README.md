# خُيُوط — التطريز اليدوي: فنٌ تتحدث فيه الخيوط

عرض تقديمي تفاعلي باللغة العربية (RTL) عن عالم التطريز اليدوي، مبني بـ HTML و CSS و JavaScript فقط، دون أي أطر عمل. تُعرض المحتويات على شكل شرائح منفصلة داخل المتصفح، بحيث تظهر شريحة واحدة في كل مرة — وليس صفحة مقالات طويلة.

## محتوى العرض

1. **الغلاف** — Title والتعريف بالعرض.
2. **ما التطريز اليدوي؟** — التعريف والقيمة الفنية والثقافية.
3. **أنواع التطريز اليدوي** — ثمانية أنواع ببطاقات بصرية (تقليدي، متقاطع، بارز، ذهبي، ساتان، سلاسل، خرز، شرائط حرير).
4. **أدوات التطريز** — الإبر، الخيوط، القماش، الطوق، المقص، قلم التحديد، والإضافات.
5. **أين نستخدم التطريز؟** — الأزياء، الإكسسوارات، الديكور، الهدايا، الفن التشكيلي، وترميم التراث.
6. **بين التراث والحداثة** — مقارنة بصرية بين التطريز التراثي والمعاصر.
7. **مشروع إبداعي** — أفكار لتحويل الحرفة إلى مشروع.
8. **الخاتمة** — "لكل غرزة حكاية" مع زر إعادة العرض.

## المميزات

- شرائح بتأثيرات ظهور ناعمة وانتقالات سلسة.
- شريط تقدم أعلى العرض + مؤشر رقم الشريحة.
- أزرار السابق / التالي / ابدأ العرض / ملء الشاشة / إعادة العرض.
- تنقل بلوحة المفاتيح: **السهم الأيمن** للتالي، **الأيسر** للسابق، **Space** للتالي، `Home` / `End` للبداية والنهاية، و `F` لملء الشاشة.
- دعم السحب بالإصبع على الجوال (سحب لليسار = التالي).
- تصميم متجاوب للكمبيوتر والجوال، مع هوية بصرية مستوحاة من الخيوط والأقمشة (عاجي، بيج، وردي غباري، أخضر زيتي، ولمسات ذهبية).

## بنية الملفات

```
.
├── index.html          # صفحة العرض وكل الشرائح الثماني
├── style.css           # الهوية البصرية والتخطيط والحركات
├── script.js           # منطق التنقل والشاشة الكاملة والتفاعل
├── README.md           # هذا الملف
└── assets/
    └── images/         # الصور المحلية (21 صورة)
```

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا بسيطًا:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.
